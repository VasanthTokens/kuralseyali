Namma Tech Stack & Architecture Decisions
1. Twilio WhatsApp Sandbox

Idhu enna pannudhu: WhatsApp messages-a programmatical ah anuppa, receive panna help pannudhu. Customer anuppura every voice note-um namma server-ku webhook vazhiya vandhurum.

Yean idha choose pannen: Meta-oda official WhatsApp Business API verification mudikka konja naalu aagum, registered business venum. Aana idhu romba fast-ana way to get a working WhatsApp integration. Dev/testing-ku totally free — billing thevai illa. Nalla documentation, periya community irukku.

Trade-off: Sandbox use pandradhala, prathi phone number-um oru 'join code' anuppanum (72 hours-ku valid). Idhu oru limitation thaan, aana production-la official Business number vaangita indha issue irukkadhu.

2. Google Gemini API (gemini-3.1-flash-lite)

Idhu enna pannudhu: Oru single API call-la rendu vela paakudhu — voice note-oda audio-va transcribe pannudhu, AND structured job details (name, issue, location, urgency, time) ellathayum JSON ah extract pannudhu, with Tamil translations.

Yean idha choose pannen:

Multimodal input: Gemini raw audio-va direct ah accept pannum. So, Speech-to-text-ku (Whisper mari) oru API, text extraction-ku innoru LLM nu separate aaga thevai illa. Oru call-la ellam mudinjirum, pipeline simple aaidum, points of failure-um kammi.

Language flexibility: Indian languages-a romba nalla handle pannudhu, namma munnatye language specify panna thevai illa; adhuve detect pannikkum.

Free tier: Oru naalaiku 500 requests tharanga, solo tradesperson-ku idhu tharalama podhum.

Structured output control: Strict JSON return panna instruct pannalam. Oru field pathi customer pesala na, guess pannama 'null' use pannum, so namma data clean ah irukkum.

Why not alternatives: Whisper use panna paid or self-hosted thevai. Claude/GPT raw audio accept panna matengudhu (naan build pannumbodhu), so extra step kandippa thevai padum.

3. Google Sheets API

Idhu enna pannudhu: Namma database idhudhaan — ovvoru job card-um oru row. Customer info, issue, status, timestamps ellathukkum separate columns.

Yean idha choose pannen:

Zero schema setup: Database server configure panna thevai illa, migrations illa, hosting thevai illa.

Completely free: Credit card thevai illa (Firebase Firestore-la sila features-ku billing enable pannanum).

Human-readable: Mano (technician) direct ah sheet-a open panni jobs-a manual ah kooda paakalam, special tooling thevai illa.

Trade-off: Sheets high-concurrency or large-scale production-ku set aagadhu. Aana indha project scale-ku idhu perfect. Future-la scale aagumbodhu Firestore or Postgres maathikalam.

4. React + Vite (Dashboard)

Idhu enna pannudhu: Idhu thaan live web dashboard. All job cards, filters, and status update buttons inga irukkum.

Yean idha choose pannen: Vite-oda dev server romba fast — near-instant hot reload kedaikkum. React ellarukkum therinjadhu, future-la extend panna easy. Backend-a every 5 seconds poll pannudhu, so WebSockets thevai illama near-real-time updates kedaikudhu.

5. Node.js + Express (Backend)

Idhu enna pannudhu: Namma server idhudhaan. Twilio webhook receive panni, Gemini-a call panni, Sheets-la write pannudhu, and dashboard-ku API serve pannudhu.

Yean idha choose pannen: Lightweight and simple. Frontend (React) and backend (Node) rendulayum JavaScript thaan. So context-switch aagama fast ah build panna mudinjadhu. Npm packages (Twilio SDK, Google APIs, Axios) irukkadhala namma scratch-la irundhu code ezhudha thevai illa.

6. ngrok (Free Static Domain)

Idhu enna pannudhu: En local server (localhost:3000)-a public internet-ku expose pannudhu, appo thaan Twilio webhook nammala reach panna mudiyum.

Yean idha choose pannen: Free static domain, so server restart pannalum URL maaradhu. Twilio-la oru thadava set panna podhum. Simple to install, server infra thevai illa.

Trade-off: Idhu development-ku mattum thaan. En laptop off aana system work aagadhu. Production-ku Render or Fly.io mari real hosting thevai.

7. google-tts-api (Tamil Voice Notes)

Idhu enna pannudhu: Short Tamil text summaries-a speech ah convert pannudhu. So, WhatsApp reply-la written job card koodave spoken voice note-um pogum — Tamil padikka theriyadhavangaluku idhu romba useful.

Yean idha choose pannen: Completely free, API key thevai illa. Google Translate-oda TTS engine use pannudhu, quality short summaries-ku nallave irukku.

Trade-off: Idhu official/documented Google product kidayadhu. Reliable ah work aagudhu, but paid production system-ku nambi irukka mudiyadhu, fallback venum.

Overall Design Philosophy (Conclusion for Judges)
Indha stack-la choose panna ovvoru piece-um ore oru constraint-a vechu thaan decide pannen: Ellame free ah irukkanum, and minimal setup irukkanum. Yeanna target user (solo tradesperson) infrastructure-ku pay panna maataru, plus hackathon-ku fast ah build panni demo pannanum.

Adhanaala thaan:

Firebase-ku badhila Sheets choose pannen.

Separate pipeline thevai illama Gemini-oda single multimodal call use pannen.

Paid TTS thevai illama Free TTS eduthen.

Real hosting time aagum nu ngrok tunnel use pannen.

The big picture: Development & demo convenience vs. Production robustness — idhudhaan inga trade-off. Oru hackathon project-ku idhu perfectly right trade-off. Production-ku pogumbodhu idhellaam eppadi swap panni robust aakkuven nu enaku clear vision irukku.
